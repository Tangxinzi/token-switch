核心能力

集中管理 Provider

维护不同服务商、中转站、自定义 API 地址和模型配置。

快速切换配置

在多个 Token、模型和 Provider 组合之间快速切换。

连通性与模型测试

检查接口状态、模型列表、延迟和基础兼容情况。

中转站监测

探测第三方中转站可用性，辅助判断服务稳定性。

本地 Relay

通过本地服务统一请求入口，并记录必要的请求状态。

高级配置入口

保留原始配置编辑、数据库查询、WebView 和桌宠窗口。
